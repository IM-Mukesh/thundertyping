# Ten card backgrounds — anime style, hero removed

Generate one at a time. Each block below is complete and self-contained.

**Why these are being regenerated:** every current cover already contains its
hero character, so the transparent cut-out that now sits on top of the card
lands on a second copy of the same person. These replace them with the same
scenes minus the hero. Enemies and vehicles stay — they are the scene, and
removing them leaves an empty room and an empty road.

**Save as:** the FILE name given, into `assets-raw/hub-v2/backgrounds/`.
